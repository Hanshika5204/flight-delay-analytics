# Flight Delay Analytics & Prediction

## Problem
Identify the key drivers of flight delays in US domestic flights and
build a model to predict delays of 15+ minutes.

## Dataset
US DOT Flight Delays and Cancellations (2015), via Kaggle.

## Approach
- Data cleaning and feature engineering
- Exploratory data analysis (delays by airline, airport, route, time)
- Statistical testing (Chi-square, ANOVA)
- Predictive modeling (Logistic Regression, Random Forest, XGBoost)
- Business impact estimation

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib, Seaborn
